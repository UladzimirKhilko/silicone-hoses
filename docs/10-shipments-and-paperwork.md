## Паспорт (на каждую отгрузку)

Шапка БСИ → «Паспорт № 09/002/25 от <дата>» → получатель → отгрузочный документ (ТТН №…) →
таблица: **наименование, кол-во, дата изготовления (07.2025), номер партии (02/25)** →
«Детали соответствуют требованиям: КД» → подпись.

Все данные паспорта уже есть в отгрузке → **сервис формирует паспорт автоматически** (Word/PDF),
с подставленным номером ТТН (в образцах поле ТТН пустое и, видимо, заполняется от руки).

## Бирки на коробки

На бирке: наименование, **номер партии (2/25)**, количество в коробке, масса, дата изготовления
(07.2025), ТНПА: КД, контролёр, и справа — число таких бирок (коробок).

Пример (к ТТН 5134450): `BSI D75L100-2` — 2 коробки по 85 шт. + 1 коробка 30 шт. = 200 шт. ✅

→ **Сервис печатает бирки автоматически**: по позиции отгрузки и вместимости коробки раскладывает
количество по коробкам и готовит лист бирок для печати.

## Что нашлось при сверке (вопросы)

| | ТТН / паспорт | Бирка |
|---|---|---|
| BSI D75L100-2, отгрузка 11.11 | 50 шт., 8,25 кг | **45 шт.**, 9,41 кг |
| BSI D75L100-3, 11.11 | 50 шт., 8,25 кг | 50 шт., 9,41 кг |
| BSI D50L100-3, 18.11 | 150 шт., 17,1 кг | 150 шт., **17,60 кг** |
| BSI D60L80-2, 19.11 | 180 шт., 19,08 кг | 180 шт., **21,4 кг** |
| BSI D75L100-2, 19.11 | 200 шт., 33 кг | 200 шт., 37,65 кг (16,0×2 + 5,65) |

Похоже, бирки правятся вручную из старого шаблона — отсюда 45 вместо 50. Массы на бирках больше,
чем в ТТН: возможно, на бирке — брутто (с коробкой), в ТТН — нетто. Автоматическая печать бирок из
данных отгрузки такие ошибки исключит.

## Номер партии и дата изготовления

Паспорт и бирки требуют **номер партии** (02/25) и **дату изготовления** (07.2025). Значит, при
приходе из Китая каждой поставке присваивается номер партии, а при отгрузке видно, из какой
партии отгружаем. Это **не** бухгалтерский партионный учёт (без себестоимости) — просто
атрибут прихода для документов и прослеживаемости.

## Заявка МТЗ

Письмо ОАО «МТЗ» от 01.07.2025 № 917-230-10-2212: «прошу изготовить в июле 2025 г.» — таблица
изделие / ед. / количество на месяц (9 позиций: D54L80-1 — 50, 90-D38L150/140-1 — 150,
30-D38L95/55-1 — 150, 90-D53L210/140-1 — 50, D50L100-3 — 50, D60L80-2 — 50, D70L100-2 — 50,
D75L100-2 — 50, D75L100-3 — 50). Оплата — 30 календарных дней после поставки.

Все 9 изделий уже есть в справочнике (совпадают с кодами на чертежах напрямую).

В сервисе: заявка вводится (или загружается со скана) → сервис показывает по каждой позиции
**«на складе / не хватает»** → отгрузки привязываются к заявке → видно **выполнение заявки**
(заказано / отгружено / осталось).
