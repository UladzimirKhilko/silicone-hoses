# 1. Видение сервиса

## Задача

Патрубки марки BSI заказываются на китайском заводе (пока один — Qinghe County Tushun Auto Parts)
и поставляются заказчикам: МТЗ, Гомсельмаш, ММЗ, БелАЗ.

Сервис — **простой складской учёт с чертежами**, а не бухгалтерская программа. Главное:

1. **Текущие остатки** — сколько чего лежит, сразу, с поиском и фильтрами.
2. **Приходы** — что и когда пришло (по поставкам из Китая).
3. **Отгрузки** — что, кому и когда отгружено.
4. **Чертёж** любого изделия — открыть в браузере в один клик и скачать.

## Решение заказчика по объёму (07.10.2026)

| Делаем | Не делаем |
|---|---|
| Остатки, приходы, отгрузки, чертежи | Себестоимость, разнесение расходов (доставка, таможня, брокер) |
| Китайская цена закупки — **справочно** (CNY, из инвойса) | Курсы валют, пересчёт в BYN, бухгалтерские проводки |
| Цена реализации в BYN — по договору/спецификации заказчика (первые цены МТЗ уже есть из ТТН) | ТТН, CMR, таможенные документы как обязательная часть |
| Загрузка прихода из инвойса и упаковочного листа завода | Партионный учёт для себестоимости, FIFO |
| Номер партии и дата изготовления — для паспорта и бирок | |

Документ про разнесение расходов ([04-cost-allocation.md](04-cost-allocation.md)) отложен —
вернёмся к нему, только если понадобится.

## Как это выглядит

**Главный экран — остатки.** Строка поиска сверху: можно ввести `90-38`, `D60`, `ЯПИБ 24.1155`,
`красный`, `МТЗ`. Таблица: код, наименование, заказчик, цвет, остаток, цена BYN, значок чертежа.
Клик по значку — чертёж открывается поверх страницы, кнопка «Скачать».

**Карточка изделия** — чертёж, параметры, остаток и лента движений: «+3000 приход TS2407202 16.01.2025»,
«−500 отгрузка МТЗ накл. №… 03.02.2025».

**Приходы** — список поставок (номер, дата, позиций, штук). Внутри — что пришло по каждой позиции.

**Отгрузки** — список (дата, заказчик, документ, штук). Новая отгрузка: выбрать заказчика, добавить
позиции поиском (сервис сразу показывает остаток и не даст отгрузить больше, чем есть).

Работает в браузере на компьютере и телефоне.
