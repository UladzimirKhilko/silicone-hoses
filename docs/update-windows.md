# Обновление «Патрубки BSI» на сервере (без git)

Для сисадмина. Сервер Windows Server, программа в `C:\Patrubki`. Время — около 10 минут,
программа недоступна 1–3 минуты.

## Что не пострадает

Обновление меняет только файлы программы. **Не трогаются**: база `C:\Patrubki\db.sqlite3`,
настройки `C:\Patrubki\.env`, чертежи и сканы `C:\Patrubki\data\media`, исходные файлы
`C:\Patrubki\data\source`, библиотеки `C:\Patrubki\.venv`. Резервную копию (по вашим правилам)
лучше сделать перед обновлением: достаточно `db.sqlite3` и папки `data\media`.

## Шаг 1. Скачать новую версию

1. Войти на GitHub под учётной записью с доступом к репозиторию (он закрытый).
2. Открыть https://github.com/UladzimirKhilko/silicone-hoses
3. Зелёная кнопка **Code** → **Download ZIP**.
   Прямая ссылка: https://github.com/UladzimirKhilko/silicone-hoses/archive/refs/heads/claude/busy-bohr-hd5pfq.zip
4. Скопировать ZIP на сервер, например в `C:\Temp\`.

## Шаг 2. Распаковать

1. Правой кнопкой по ZIP → **Свойства** → внизу отметить **Разблокировать** → **ОК**
   (если такого пункта нет — пропустить).
2. Правой кнопкой → **Извлечь всё…** → в `C:\Temp\`.
3. Должна появиться папка `C:\Temp\silicone-hoses-claude-busy-bohr-hd5pfq`
   (внутри — папки `deploy`, `catalog`, `stock`, файл `manage.py` и т. д.).

> Распаковывать **не** в `C:\Patrubki` — скрипт сам перенесёт файлы.

## Шаг 3. Запустить обновление

Пуск → ввести `PowerShell` → правой кнопкой → **Запуск от имени администратора**. Выполнить:

```powershell
powershell -ExecutionPolicy Bypass -File C:\Temp\silicone-hoses-claude-busy-bohr-hd5pfq\deploy\windows\update-from-zip.ps1
```

Скрипт:
1. остановит программу (задача планировщика «Patrubki BSI»);
2. скопирует новые файлы в `C:\Patrubki` (база, `.env`, чертежи не копируются и не удаляются);
3. обновит библиотеки Python (нужен интернет на сервере, как при установке);
4. обновит структуру базы, роли пользователей и оформление;
5. докачает новые файлы с Яндекс.Диска, прикрепит новые чертежи и загрузит приходы из папки «Закупки»
   и таблицы учёта Амкадора (.xlsx прямо в папке «Закупки/Амкадор -Пинск»), затем отчёты бухгалтерии (1С)
   из папки «Бухгалтерия»
   (уже загруженные поставки пропускаются; если интернета нет — шаг пропускается с жёлтым предупреждением);
6. запустит программу и напишет **«Обновлено. Версия: …»** зелёным.

Если программа стоит не в `C:\Patrubki`, добавьте в конец команды `-Target D:\Папка\Программы`.

## Шаг 4. Проверить

1. На любом компьютере открыть программу (например, `http://192.168.9.2:8000`) и нажать **Ctrl+F5**.
2. Внизу левого меню (и на странице входа) должно быть **«Версия 6.7.3 от 28.10.2026»**
   (или новее). Слева — меню «Сводка, Остатки, Приходы…», на главной — сводка с графиком.
3. Папку `C:\Temp\silicone-hoses-claude-busy-bohr-hd5pfq` и ZIP можно удалить.

## Если что-то пошло не так

| Что видно | Что сделать |
|---|---|
| «Выполнение сценариев отключено» | Запускать именно командой из шага 3 (с `-ExecutionPolicy Bypass`) |
| «В C:\Patrubki не найдена установленная программа» | Указать правильную папку: `-Target <папка>` |
| Ошибка на `pip install` | Проверить интернет на сервере / прокси; запустить шаг 3 ещё раз |
| Красный текст с ошибкой в другом месте | Скопировать весь текст окна PowerShell и прислать разработчику |
| Программа не открывается после обновления | Пуск → «Планировщик заданий» → задача **Patrubki BSI** → **Выполнить** |
| Старый вид после обновления | В браузере **Ctrl+F5**; проверить версию внизу меню |

Повторный запуск шага 3 безопасен.
