# 11. Текущий учёт в Excel: «Учет патрубков МТЗ.xlsx»

Получено 07.10.2026. Выгрузка данных: [data/mtz-stock-from-excel.csv](data/mtz-stock-from-excel.csv).

## Как устроена таблица

Один лист, одна строка на изделие (25 изделий МТЗ):

| Блок | Столбцы | Содержимое |
|---|---|---|
| ПРИХОД | C–J | цена Китая (CNY); приходы по датам **04.03.2024, 08.02.2025, 18.09.2025, 04.11.2025, 19.11.2025**; итого шт.; сумма CNY |
| РАСХОД | L–AH | согласованная цена МТЗ (BYN без НДС); отгрузки по месяцам (июль 2025 … март 2026) и датам; сумма за месяц; итого шт. и BYN |
| Остаток | AI | итого приход − итого реализовано |
| МТЗ | AJ–AN | «цена за шт. приходная (ТЗР+таможня)» — вводится вручную; расчёт месячной заявки (март) |
| Внизу | | закупочный бюджет: МТЗ 3 756,2; **МАЗ МАН** 5 300; итого 9 056,2 |

Итоги на сегодня: **приход 25 104 шт., реализовано 10 891 шт., остаток 14 213 шт.**

## Что показала проверка формул

Каждая строка считается **своей формулой, поправленной вручную** — формулы в разных строках разные:

- «Итого приход» в 21 строке = D+E+F, в двух строках добавлен H, ещё в двух — G. Новая дата прихода
  требует вручную дописать столбец в формулу нужной строки.
- «Итого реализовано» — 4 разных варианта формулы (с X, с AA, с Z+Q или без них).

Сейчас количества сходятся — я пересчитал все 25 строк по столбцам. Найдено:

| Где | Что |
|---|---|
| Строка 10, BSI D75L100-3, ноябрь | отгрузка 50 шт. от 11.11 учтена в штуках и остатке, но **не попала в сумму реализации за ноябрь** (нет формулы): ноябрь занижен на **449,50 BYN** |
| BSI D50L100-3, 150 шт. | по ТТН 5134443 отгружено **18.11.2025**, а в таблице стоит в столбце **11.11** |

Это ровно то, что сервис исключает: остаток считается автоматически из всех приходов и отгрузок,
дата берётся из документа.

## Что это даёт сервису

1. **Стартовые данные готовы**: по 25 изделиям МТЗ — все приходы с датами, все отгрузки, остатки,
   цены Китая и согласованные цены МТЗ. Перенесём в сервис как историю, а не только как остаток.
2. Приход **08.02.2025** = поставка TS2407202 (кол-ва совпадают с инвойсом: 4 шт. образцов,
   1 500 / 3 000 / 2 010 серийных). Приход **04.03.2024** — образцы по 3 шт.
3. Пометка **«спц. Закончилась»** у `90-D38L150/140-1` и `30-D38L95/55-1` → у спецификации
   заказчика есть **лимит по количеству**. Сервис может показывать остаток по спецификации.
4. Столбец **«Расчёт месячной заявки»** — сервис будет считать сам: заявка − остаток.
5. Есть **«приходная цена (ТЗР+таможня)»**, введённая вручную, и строка «разница между ценой
   реализации/закупки» → возможно, нужна простая маржа (не бухгалтерия): поле «приходная цена за шт.»
   по партии, которое вы вписываете сами.
6. Новые изделия без чертежей: `BSI 90-D53L200/150-1`, `BSI D203L320-COR-1` (нулевые строки).
7. Новый заказчик: **МАЗ МАН** (только в бюджете закупки).
