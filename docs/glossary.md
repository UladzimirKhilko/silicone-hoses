# Глоссарий

| Термин | Значение |
|---|---|
| Патрубок / изделие / SKU | Единица номенклатуры: конкретный патрубок с конкретными параметрами |
| Завод (Factory) | Китайский производитель/поставщик |
| Код завода | Артикул изделия в документах завода. У одного изделия на разных заводах разные коды |
| PO (Purchase Order) | Наш заказ на завод |
| PI (Proforma Invoice) | Предварительный счёт завода на оплату |
| CI / Инвойс (Commercial Invoice) | Коммерческий инвойс на отгрузку: позиции, кол-во, цена, сумма |
| PL / Упаковочный лист (Packing List) | Перечень коробок: что в какой коробке, сколько штук, вес нетто/брутто, габариты |
| CTN | Carton — коробка / грузовое место |
| N.W. / G.W. | Net / Gross Weight — вес нетто / брутто |
| CBM | Кубометры, объём груза |
| ТТН | Товарно-транспортная накладная (РБ) |
| CMR | Международная автомобильная накладная |
| СМГС | Накладная для ЖД-перевозки |
| Поставка / партия (Shipment) | Одна физическая отправка: 1+ инвойсов, PL, транспортные документы, расходы |
| Landed cost / себестоимость | Цена завода + доля всех расходов на доставку и растаможку, на единицу |
| База распределения | Показатель, пропорционально которому делится расход: вес, стоимость, объём, кол-во мест, шт. |
| Резерв | Количество, закреплённое за заявкой клиента, но ещё не отгруженное |
| MOQ | Минимальная партия заказа на заводе |
| Кратность | Заказ кратно количеству в коробке |
| Точка перезаказа | Остаток, при котором пора заказывать |
| Код ТН ВЭД | Классификатор товара для таможни. В ваших инвойсах — **3917310008** |
| BSI | Марка изделий ОАО «БПА БЕЛСТРОЙИНДУСТРИЯ» |
| Код BSI | Наименование изделия по штампу чертежа. Две системы: параметрическая (`BSI 90-D38L150/140-1`) и номинальная ММЗ (`BSI 90-38-01`). **Не уникален** — ключ изделия ЯПИБ (см. 09) |
| Синоним | Написание изделия в чужом документе (инвойс, PL, заявка), подтверждённое человеком и привязанное к ЯПИБ |
| Суффикс `-1/-2/-3` | Обозначение цвета: чёрный / синий / красный. Разный цвет = разное изделие (свой чертёж) |
| ЯПИБ 24.xxxx | Обозначение чертежа — **уникальный ключ изделия** |
| Заказчик | Предприятие, для которого делается изделие: МТЗ, Гомсельмаш, ММЗ, БелАЗ |
| Образец | Пробная партия 3–5 шт. для согласования с заказчиком |
| Смешанная коробка | Коробка с несколькими позициями; вес дан на коробку целиком |
| Q571, Q595… | Номера заказов на заводе, которые закрывает отгрузка |
