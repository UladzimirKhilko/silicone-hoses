# Установка на Windows Server 2019 — инструкция для администратора

На Windows Server 2019 **Docker Desktop не поддерживается** (он рассчитан на Windows 10/11),
WSL 2 на этой версии тоже нет. Поэтому здесь программа ставится **напрямую в Windows, без Docker**:
Python + встроенная база SQLite + веб-сервер waitress. Для 2–3 пользователей этого достаточно.

Установка — **один скрипт**, примерно 15–30 минут (большая часть — скачивание).

## Требования

| | |
|---|---|
| ОС | Windows Server 2019 (подойдут также 2016/2022, Windows 10/11) |
| Память / диск | 2 ГБ / 5 ГБ свободно |
| Python | 3.12 (64-bit) с python.org |
| Права | Администратор (скрипт создаёт правило брандмауэра и задачу планировщика) |
| Интернет | Нужен при установке и обновлении (библиотеки Python, папка с Яндекс.Диска) |
| Порт | 8000 (можно другой) |

## 1. Установить Python

1. Скачать **Python 3.12, Windows installer (64-bit)**: https://www.python.org/downloads/windows/
2. При установке отметить **«Add python.exe to PATH»** и выбрать «Install for all users»
   (Customize installation → Install Python for all users) — чтобы задачи планировщика от SYSTEM его видели.

## 2. Скопировать программу

Например, в `C:\Patrubki`:

- через git: `git clone https://github.com/UladzimirKhilko/silicone-hoses.git C:\Patrubki`
  и `git checkout claude/busy-bohr-hd5pfq` (до слияния в основную ветку);
- или скачать ZIP на GitHub (**Code → Download ZIP**) и распаковать в `C:\Patrubki`.

Репозиторий закрытый — нужен доступ к GitHub (логин на чтение).

## 3. Запустить установку

PowerShell **от имени администратора**:

```powershell
cd C:\Patrubki
powershell -ExecutionPolicy Bypass -File deploy\windows\install.ps1
```

Скрипт:
1. создаст окружение Python и установит библиотеки;
2. создаст файл настроек `C:\Patrubki\.env` (секретный ключ, адреса сервера, порт 8000);
3. создаст базу, скачает чертежи с Яндекс.Диска, загрузит 103 изделия и историю МТЗ;
4. попросит придумать **логин и пароль администратора**;
5. откроет порт 8000 в брандмауэре и создаст задачу планировщика **«Patrubki BSI»** —
   программа запускается вместе с сервером и перезапускается при сбое.

Другой порт: `install.ps1 -Port 8080`.

В конце скрипт покажет адрес, например `http://SERVER01:8000` или `http://192.168.1.10:8000`.
Повторный запуск безопасен.

## 4. Пользователи

В браузере: `http://<сервер>:8000/admin/` → **Пользователи** → **Добавить** → указать группу
**«Руководитель»** или **«Менеджер»**.

## Доступ с телефона вне офиса

Рекомендуем **VPN** в сеть предприятия: программа остаётся внутренней. Публиковать её в интернет
напрямую (порт 8000 без HTTPS) **не нужно**. Если всё же нужен внешний адрес — через IIS
(обратный прокси + сертификат) или отдельный прокси с HTTPS; это настраивается дополнительно.

## Резервные копии

Автоматическое ежедневное копирование скрипт **не настраивает** — резервирование по правилам
предприятия. Что сохранять: файл `C:\Patrubki\db.sqlite3` (база) и папку `C:\Patrubki\data\media`
(чертежи, сканы ТТН).

Готовая команда — база и файлы в один ZIP (база копируется корректно даже во время работы):

```powershell
C:\Patrubki\.venv\Scripts\python.exe C:\Patrubki\manage.py backup C:\Backups\Patrubki
```

Восстановление: остановить задачу «Patrubki BSI», распаковать ZIP — `db.sqlite3` в `C:\Patrubki\`,
папку `media` в `C:\Patrubki\data\` — и снова запустить задачу.

## Обновление (новые версии)

1. Заменить файлы программы новой версией (`git pull` или распаковать новый ZIP поверх;
   **не трогать** `.env`, папки `data` и `.venv`, файл `db.sqlite3`).
2. PowerShell от имени администратора:

```powershell
cd C:\Patrubki
powershell -ExecutionPolicy Bypass -File deploy\windows\update.ps1
```

Скрипт перед обновлением сделает одну резервную копию в `C:\Backups\Patrubki` (другая папка:
`update.ps1 -BackupDir D:\Backups`), обновит библиотеки и базу и перезапустит программу.

Новые чертежи, добавленные на Яндекс.Диск, подтягиваются повторным запуском `install.ps1`.

## Если что-то не работает

| Признак | Что проверить |
|---|---|
| Страница не открывается с других компьютеров | Правило брандмауэра «Patrubki BSI», порт в `.env` (`PORT`) |
| «Bad Request (400)» | Адрес, по которому открывают, добавить в `DJANGO_ALLOWED_HOSTS` в `.env`, перезапустить задачу |
| Программа не запускается после перезагрузки | Планировщик заданий → «Patrubki BSI» → журнал; Python установлен «для всех пользователей» |
| Скрипт не скачивает с Яндекс.Диска | Доступ сервера в интернет / прокси предприятия |
| `HTTP Error 500` при скачивании | Временный отказ Яндекс.Диска. Скрипт сам повторяет запросы и заходы; если всё же остановился — запустить `install.ps1` ещё раз, скачанное не повторяется |

Ручной запуск для проверки (видно ошибки):
`C:\Patrubki\.venv\Scripts\python.exe C:\Patrubki\deploy\windows\serve.py`
