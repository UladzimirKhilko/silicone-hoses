# 7. Что нужно от вас

## 7.1 Доступ к образцам (срочно)

Ссылка на Яндекс.Диск (`disk.yandex.by/d/L4tPbTCYDqEIEA`) **недоступна** из моей облачной среды —
сетевая политика окружения блокирует хосты Яндекса. Два варианта:

1. **Открыть доступ**: в настройках облачного окружения (меню окружения в заголовке сессии → Edit →
   Network access) добавить в Allowed domains: `cloud-api.yandex.net`, `disk.yandex.by`,
   `disk.yandex.ru`, `downloader.disk.yandex.ru`, `*.storage.yandex.net`.
   Инструкция: https://code.claude.com/docs/en/cloud-environments#network-access
2. **Или положить файлы в репозиторий** в папку `samples/` (структура в `samples/README.md`).

## 7.2 Документы-образцы

По **каждому** заводу, с которым работаете (лучше по 2 разных поставки):

- [ ] Инвойс (в том виде, как приходит: xlsx/pdf)
- [ ] Упаковочный лист от завода (китайский/англ.)
- [ ] Упаковочный лист на русском (кто его делает — вы, завод, экспедитор?)
- [ ] ТТН и/или CMR / СМГС
- [ ] Счета за доставку, экспедирование, брокера, СВХ
- [ ] Таможенная декларация или расчёт таможенных платежей
- [ ] Ваш заказ на завод (PO), как вы его сейчас отправляете
- [ ] Чертежи (уже есть частично) — желательно, чтобы имя файла содержало код изделия
- [ ] 3–5 примеров заявок клиентов — как реально приходят (Excel, письмо, мессенджер, фото)
- [ ] Текущий учёт: Excel с номенклатурой / остатками / себестоимостью, если есть

## 7.3 Вопросы

**Номенклатура**
1. Сколько примерно наименований сейчас и сколько заводов?
2. Есть ли у вас свой внутренний артикул? Как вы сейчас называете изделие (по коду завода, по чертежу, по параметрам)?
3. Одно и то же изделие может делать несколько заводов?
4. Продаёте только штуками или также метражом (рукава в бухтах)?

**Поставки**
5. Как везёте: авто, ЖД, море+авто? Бывают ли сборные поставки от нескольких заводов в одной машине?
6. Один инвойс = одна поставка? Бывают ли частичные отгрузки по одному заказу?
7. В какой валюте инвойсы (USD/CNY)? Как платите (предоплата/после отгрузки)?
8. Какие расходы бывают в поставке? Как сейчас делите их по позициям (по весу, по сумме)?

**Учёт**
9. Курс для себестоимости — на какую дату (оплаты, ввоза, выпуска декларации)?
10. НДС при импорте включать в себестоимость или нет? Валюта учёта — BYN?
11. Списание при продаже — по партиям (FIFO) или по средней?
12. Ведёте ли 1С (какая конфигурация)? Нужен ли обмен? Где ведутся продажи клиентам — здесь или в 1С?
13. Сколько складов?

**Заявки и закупка**
14. Кто клиенты (оптовики, СТО, розница)? Нужны ли цены продажи и прайс-листы в сервисе?
15. Есть ли у заводов MOQ, кратность, сроки производства? Знаете ли вы шт. в коробке для каждого изделия?
16. В каком формате и на каком языке заводы хотят получать заказ?

**Работа с сервисом**
17. Кто будет работать (сколько человек, роли)? Нужен ли доступ с телефона?
18. Где размещать: облачный сервер (VPS) — ок? Есть ли требования хранить данные в РБ?
19. Разрешаете ли отправку документов в ИИ-распознавание (Claude API)? Тогда понадобится API-ключ Anthropic (оплата по факту использования, порядок — единицы $ в месяц при ваших объёмах).
20. Бюджет на сервер (~10–30 $/мес) — ок?

## 7.4 Доступы на этапе разработки/запуска

- Яндекс.Диск — см. 7.1.
- Позже: VPS (или доступ к вашему хостингу), домен, API-ключ Anthropic — через секреты окружения,
  **не в чате и не в репозитории**.

## 7.5 Какие навыки (skills) и инструменты мне понадобятся

**Уже есть в этой среде и пригодятся:**

| Навык | Для чего |
|---|---|
| `xlsx` | разбор инвойсов/PL в Excel, генерация заказов в Китай и отчётов |
| `pdf` | извлечение таблиц из PDF-инвойсов, чертежи, OCR сканов |
| `docx` | если какие-то документы приходят в Word |
| `zhd-specifikatsiya` | у вас уже есть навык ЖД-спецификации из инвойса + PL — переиспользуем логику/шаблоны |
| `claude-api` | правильная интеграция ИИ-распознавания |
| `code-review`, `security-review` | проверка кода перед слиянием |
| `session-start-hook` | автозапуск тестов/линтеров в облачных сессиях |

**Создадим под проект** (через `skill-creator`, хранятся в репозитории в `.claude/skills/`):

- `hoses-domain` — глоссарий, правила именования изделий, разбор параметров патрубка
  («угол 90° 51×300×300 4 слоя синий» → структура).
- `factory-doc-parsers` — как добавить профиль нового завода/формата (образец → профиль → тест).
- `cost-allocation-rules` — утверждённые правила разнесения расходов, чтобы не терять решения бухгалтера.

**Сетевые доступы:** Яндекс.Диск (см. выше), позже — API НБРБ (`api.nbrb.by`) для курсов.
