- Колонки: маркировка на коробке (кит. описание вида `38*150*140 90度`), модель (`BSI 90-D38L150/140-1`),
  цвет, размер коробки, объём/коробку, шт./коробку, кол-во коробок, нетто/брутто на коробку, итоги, № коробок (`11--17`).
- **Одна позиция повторяется во многих строках** с разным кол-вом в коробке (80, 40 шт.) — надо суммировать.
- **Смешанные коробки:** образцы упакованы по 13–25 позиций в одну коробку (маркировки `TS2407202-B…E`).
  Вес и объём дан **только на коробку** → вес по позициям надо делить расчётом (по массе 1 шт. из чертежа).
- Справа в колонках P–T — промежуточные итоги по паллетам/группам (служебные, при разборе игнорировать).
- Лист `Sheet2` — рабочий черновик с ошибками (например, `38*150*40`), не использовать.

## Что это меняет в проекте

1. Завод пока один → интерфейс без выбора завода, но модель данных многозаводская (заложено).
2. Появляется **заказчик изделия** (МТЗ/ГСМ/ММЗ) и **статус согласования чертежа** (на согласовании → согласован).
3. Различаем **образцы** и **серию** — для заявок и аналитики.
4. Один инвойс ↔ несколько заказов завода (Q571, Q595, Q604) — уже заложено в модели.
5. Обязательно: деление веса смешанных коробок по массе 1 шт.
6. Парсер имени изделия (код BSI → параметры) — основа для поиска и сопоставления заявок.
