# 12. Готовые решения vs своя разработка

> ✅ **Решение заказчика (07.10.2026): делаем свою разработку.** План — [06-roadmap.md](06-roadmap.md).

Вопрос заказчика (07.10.2026): нельзя ли взять готовое решение и адаптировать?

## Что нам нужно (из docs 01, 09, 10, 11)

| # | Требование | Насколько типовое |
|---|---|---|
| 1 | Остатки, приходы, отгрузки | типовое — есть везде |
| 2 | Номер партии + дата изготовления | типовое (серии / lots / batch) |
| 3 | Чертёж в карточке: открыть и скачать | почти типовое (вложение к товару) |
| 4 | Паспорт и бирки по шаблону, раскладка по коробкам из PL | шаблоны печати есть, **раскладка по коробкам — доработка** |
| 5 | Загрузка прихода из китайского PL (смешанные коробки, повторы строк) | **доработка везде** |
| 6 | Изделие = чертёж (ЯПИБ), синонимы названий из инвойса / PL / ТТН | **нетиповое** — в готовых системах товар ищется по названию/артикулу |
| 7 | Цены по спецификации заказчика, лимит спецификации | частично (прайс по контрагенту есть, лимит — доработка) |
| 8 | Заявки заказчиков: «есть / не хватает», выполнение | типовое (заказ покупателя) |

## Варианты

| | **1С** (Управление торговлей / Склад) | **МойСклад** (облако) | **InvenTree** (open source) | **Своя разработка** |
|---|---|---|---|---|
| Что это | Учётная система, стандарт в РБ | Облачный складской сервис, работает в РБ | Бесплатная система складского учёта деталей (Python/Django) | Сервис под ваши процессы (docs 06) |
| Остатки / приходы / отгрузки | ✅ | ✅ | ✅ | ✅ |
| Партии | ✅ серии | ✅ серии | ✅ batch code | ✅ |
| Чертежи | файлы к номенклатуре, просмотр через внешнюю программу | файлы к товару, скачать | вложения к детали, PDF в браузере | просмотр в один клик |
| Паспорт, бирки | программист 1С делает печатные формы | свои шаблоны печатных форм (Excel) | шаблоны отчётов и этикеток (HTML) | ✅ по вашим образцам |
| Импорт китайского PL | обработка 1С на заказ | только загрузка из Excel по их шаблону — PL придётся переделывать руками | плагин на Python (могу написать) | ✅ |
| Синонимы, изделие = чертёж | доработка | ❌ нет | плагин / доработка | ✅ |
| Стоимость | лицензии + программист 1С | подписка ежемесячно | бесплатно + сервер ~10–20 $/мес | сервер ~10–20 $/мес |
| Срок до работы | зависит от программиста | 1–3 дня (без доработок) | ~2 нед. (установка + плагины) | ~4–5 нед. |
| Минусы | дорого дорабатывать, неудобно с телефона | ваши особенности (PL, синонимы, бирки) не закрывает; данные у сервиса | интерфейс «инженерный», перевод на русский неполный, много лишнего | дольше старт |

## Рекомендация

1. **Если у БСИ уже есть 1С** (ТТН, скорее всего, печатаются оттуда) — сначала спросить вашего
   программиста 1С, сколько стоит доработка: партии + файлы чертежей + печать паспорта и бирок +
   загрузка PL. Учёт в одной системе с бухгалтерией — большое преимущество.
2. **Если 1С нет или дорабатывать дорого** — я бы выбрал между:
   - **InvenTree + мои плагины** — быстрее (~2 недели), бесплатно, закрывает почти всё;
     компромисс — интерфейс сложнее, чем нужно.
   - **Своя разработка** — дольше (~4–5 недель), но ровно ваши экраны, простой интерфейс
     для склада и телефона, ваши правила (чертёж = изделие, бирки из PL).
3. **МойСклад** — подходит, если нужно «завтра» и согласны вести приход вручную и печатать бирки
   по шаблону без раскладки. Можно попробовать бесплатный пробный период и сравнить.

Перед выбором можно за 1–2 дня поднять **InvenTree с вашими 25 изделиями МТЗ, чертежами и
остатками** — посмотрите вживую и решите.
