# 13. Итоги интервью с заказчиком (07.10.2026)

Решение: **своя разработка** ([12-ready-solutions.md](12-ready-solutions.md)).

## 1. Пользователи и доступ

| Вопрос | Ответ | Что делаем |
|---|---|---|
| Сколько человек | 2–3 | Простой вход по логину/паролю |
| Роли | Руководитель, менеджер/снабженец (кладовщика нет) | Две роли: **руководитель** (всё + цены/маржа), **менеджер** (всё, кроме настроек). Приход, отгрузку и печать бирок делает менеджер |
| Устройства | Компьютер в офисе + телефон | Адаптивный интерфейс; на телефоне в первую очередь — поиск, остаток, чертёж |
| Размещение | «На сервере» | Облачный сервер (VPS), домен, HTTPS, ежедневные копии базы |

## 2. Склад и остатки

| Вопрос | Ответ | Что делаем |
|---|---|---|
| Склады | Один | Один склад, без адресного хранения |
| Старт учёта | Вся история из Excel | Переносим все приходы и отгрузки из «Учет патрубков МТЗ.xlsx» с датами |
| Другой товар (образцы ГСМ/ММЗ, рукава БелАЗ, МАЗ МАН) | Разберёмся позже | Заводим справочник по чертежам; остатки по ним — после уточнения |
| Исключения | Брак из Китая, недостача при приёмке, бесплатные образцы | Три вида списания с причиной и комментарием |

## 3. Приход из Китая

| Вопрос | Ответ | Что делаем |
|---|---|---|
| Когда в остатках | После приёмки на складе | Поставка: «в пути» → «принято»; при приёмке — факт, расхождения уходят в списание «недостача» |
| Частота | Раз в квартал | — |
| Видеть заказанное | Да, без дат | Колонка **«в пути»** в остатках |
| Приходная цена (ТЗР+таможня) | Да, ввожу вручную | Поле «приходная цена за шт., BYN» в партии; маржа = цена реализации − приходная |

## 4. Отгрузки и заказчики

| Вопрос | Ответ | Что делаем |
|---|---|---|
| ТТН | Оформляется в 1С | В сервисе: номер, дата, скан ТТН |
| Спецификация | Следить за остатком лимита | Спецификация: изделия, цены, лимит шт.; остаток по лимиту, предупреждение при превышении |
| Заказчики | МТЗ, **Амкадор**, Гомсельмаш, ММЗ, БелАЗ, МАЗ МАН | Справочник заказчиков с договорами |

## 5. Чертежи

| Вопрос | Ответ | Что делаем |
|---|---|---|
| Кто делает | Свой конструктор в AutoCAD | — |
| Какие файлы | PDF, скан с подписями согласования, версия для китайского завода | Три типа файла у чертежа |
| Версии | Редко, достаточно заменить | Замена файла (старый не храним) |
| Зачем | Посмотреть, отправить в Китай, отправить заказчику | Просмотр в браузере, скачать; **архив чертежей** по выбранным изделиям (для заказа / заявки) |

## 6. Заявки и заказ в Китай

| Вопрос | Ответ | Что делаем |
|---|---|---|
| Откуда заявки | Тендерные площадки, скан письма, Excel, телефон/мессенджер | Ручной ввод + вставка из Excel; скан — прикрепляем файл |
| Что делать с заявкой | Есть/не хватает, выполнение, резерв, подсказка для заказа в Китай | Всё четыре |
| Заказ в Китай | Через мессенджер (WeChat) | Сервис готовит **текст списка для копирования** (код, кол-во, на англ.) + архив чертежей |
| Статусы заказа | Достаточно «в пути» | Заказ: «в пути» → «пришёл» (связан с поставкой) |

## 7. Отчёты, 1С, приоритеты

| Вопрос | Ответ |
|---|---|
| Отчёты | Отгрузки за месяц по заказчикам (шт. и BYN), маржа, «заканчивается товар», выгрузка всего в Excel |
| 1С | Живём отдельно |
| Уведомления | Не нужны |
| Приоритет первой версии | **Все четыре блока**: остатки+чертежи, приходы+отгрузки, паспорт+бирки, заявки+заказ в Китай |
