# 6. План разработки

Своя разработка, объём по итогам интервью ([13-interview.md](13-interview.md)): остатки, приходы,
отгрузки, чертежи, паспорт и бирки, заявки и заказ в Китай. Без бухгалтерии и себестоимости.
После каждого этапа — рабочая версия на сервере.

| Этап | Что получаем | Срок |
|---|---|---|
| **0. Анализ** ✅ | Разбор документов, правила идентификации изделий, интервью | сделано |
| **1. Справочник и чертежи** ✅ на проверке | Каркас, вход (руководитель / менеджер). Изделия по чертежам МТЗ / ГСМ / ММЗ + рукава БелАЗ, заказчики. Просмотр, скачивание, архив чертежей. Поиск. Работает с телефона | 1 нед. |
| **2. Остатки, приходы, отгрузки** ✅ на проверке | Перенос истории из Excel МТЗ. Приход партии (номер партии, дата изготовления, приходная цена, коробки из PL), приёмка с расхождениями, отгрузки со сканом ТТН, списания, «в пути». Карточка изделия с движениями. **Можно работать.** | 1–2 нед. |
| **3. Паспорт и бирки** ✅ на проверке | Кнопки «Паспорт» и «Бирки» в отгрузке; раскладка по коробкам и масса из PL | 3–4 дня |
| **4. Загрузка прихода из файлов** ✅ на проверке | «Приходы → Загрузить из файлов завода»: инвойс (xlsx) + упаковочный лист (xls/xlsx) → разбор, сопоставление с изделиями по коду и синонимам, сверка количеств инвойс/PL, предупреждение о повторной загрузке, выбор изделия для неоднозначных строк, коробки и вес из PL → поставка «в пути». Новые написания запоминаются как синонимы | 1 нед. |
| **5. Цены, договоры, заявки, заказ в Китай** ✅ на проверке | Цена завода / учётная (курс + расходы партии) / продажи; прибыль и маржа в отгрузках, отчёт «Прибыль» (месяцы, заказчики, изделия, Excel), склад по учётным ценам — только руководителю. Договоры и спецификации с ценами и лимитами (вставка из Excel, цена и лимит в отгрузке). Заявки: есть / не хватает / резерв / выполнение, отгрузка по заявке. Заказ в Китай: подсказка до целой коробки, текст для WeChat, чертежи ZIP, «в пути» → инвойс (docs/15) | 1–1,5 нед. |
| **6. Интерфейс, отчёты, запуск** ✅ на проверке | Новый интерфейс (меню по разделам, поиск отовсюду, телефон, тёмная тема). Сводка с графиком. Отчёты: отгрузки по месяцам по заказчикам/изделиям, «Заканчивается» (+ в заказ в Китай), Excel во всех списках. Справка для обучения (docs/16). Пакет установки на Windows Server ✅ | 3–5 дней |

**Полная первая версия: ~5–7 недель.** Работать можно с конца этапа 2 (~3 недели).

## Технологии

Python + Django, PostgreSQL, интерфейс Django-шаблоны + HTMX (быстро, работает на телефоне),
просмотр PDF — PDF.js, документы — openpyxl/docx. Сервер — Windows Server предприятия (или Docker); резервное копирование — силами сисадмина.

## Как работаем

- Код — в этом репозитории, каждый этап — отдельный pull request.
- Разбор файлов покрыт тестами на ваших реальных документах.
- После каждого этапа — ссылка на рабочую версию и список «что проверить».
