# 4. Разнесение расходов и себестоимость

> ⏸ **Отложено** (решение заказчика 07.10.2026): сервис не считает себестоимость. Китайская цена
> хранится только справочно. Документ оставлен на случай, если это понадобится позже.

## Принцип

Себестоимость единицы = цена завода (в BYN по курсу) + Σ долей всех расходов поставки / кол-во.

Каждый расход делится между строками поставки **пропорционально базе распределения**:

```
доля_строки = база_строки / Σ база_всех_строк
расход_на_строку = сумма_расхода × доля_строки
себестоимость_ед = (стоимость_строки_BYN + Σ расход_на_строку) / кол-во_шт
```

## Базы распределения (настраиваются по типу расхода)

| Тип расхода | База по умолчанию | Почему |
|---|---|---|
| Фрахт, доставка, экспедирование | вес брутто (из PL) | платим за кг/машину |
| Доставка при «лёгком объёмном» грузе | объём (CBM) | если перевозчик считает по объёму |
| Таможенная пошлина | таможенная стоимость строки / по фактической графе декларации | пошлина начисляется от стоимости |
| НДС при импорте | обычно не в себестоимость (к вычету) — **уточнить у бухгалтера** | |
| Брокер, СВХ, сборы | стоимость или кол-во мест | договорённость |
| Банковская комиссия, курсовая разница | стоимость (инвойс) | привязано к оплате |
| Разгрузка, склад | кол-во мест или вес | |

Можно разнести расход и вручную (указать конкретные строки или доли).

## Пример

Поставка: 2 позиции, фрахт 1 000 BYN по весу брутто, брокер 300 BYN по стоимости.

| Позиция | Шт | Цена, $ | Сумма, $ | Брутто, кг | Фрахт | Брокер |
|---|---|---|---|---|---|---|
| Угол 90° D51 | 200 | 3.00 | 600 | 150 | 1000×150/250 = 600 | 300×600/1000 = 180 |
| Прямой D76 L1000 | 100 | 4.00 | 400 | 100 | 400 | 120 |

При курсе 3.2 BYN/$ себестоимость угла D51 = (600×3.2 + 600 + 180) / 200 = **13.50 BYN/шт**.

## Особенности

- **Вес по строке.** Если в PL вес дан только на коробку/смешанную коробку — делим вес коробки
  между позициями пропорционально штукам × весу 1 шт. из справочника.
- **Курс.** Для товара — курс на дату ... (оплаты? ввоза? — **решение за вашим бухгалтером**).
- **Поздние расходы.** Расход, пришедший после продажи части товара, корректирует себестоимость
  партии; отчёт показывает до/после.
- **Метод списания** для себестоимости продаж: по партиям (FIFO) или средняя — **на выбор**.
- **Округления** — остаток копеек относится на самую крупную строку, чтобы сумма сошлась точно.
