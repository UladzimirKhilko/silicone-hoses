# Образцы документов

Структура (предлагаемая):

```
samples/
  invoices/          # инвойсы заводов (xlsx/pdf), по одному-два от каждого завода
  packing-lists/
    cn/              # упаковочные листы от китайцев (англ./кит.)
    ru/              # упаковочные листы на русском
  ttn/               # ТТН / CMR
  customs/           # декларации, расчёт платежей, счета брокера
  expenses/          # счета за фрахт, экспедирование, СВХ и т.п.
  drawings/<завод>/  # чертежи патрубков
  requests/          # примеры заявок клиентов (как они реально приходят)
  orders-to-china/   # примеры заказов, которые вы отправляете на завод
  nomenclature/      # текущий список номенклатуры / остатков (Excel)
```

Если документы содержат коммерческую тайну — можно обезличить цены/реквизиты,
но структуру (колонки, формат, язык) сохраняйте как в оригинале.
