{% icon "search" %} Найти изделие и чертёж

  1. Начните вводить в строке поиска вверху: код (90-D38), ЯПИБ (24.1129) или размер. Клавиша / сразу ставит курсор в поиск.
  2. В карточке изделия — чертёж (вкладки: PDF BSI, скан с подписями, чертёж завода, чертёж заказчика), остаток по партиям, цены, движение.
  3. Чтобы отправить чертежи пачкой: на странице «Остатки» отметьте изделия галочками → «Скачать чертежи (ZIP)».

{% icon "package-plus" %} Приход из Китая

  1. «Приходы» → «Загрузить из файлов завода»: перетащите файлы завода (инвойс и/или упаковочный лист) — Excel или PDF, с любыми именами. Сервис сам определит, где инвойс, а где упаковочный лист. PDF — сохранённый из Excel или программы; скан-картинку прочитать нельзя.
  2. Проверьте таблицу: подсвеченные строки — выберите изделие из списка (одинаковый код у разных заказчиков). Если товар заказывали через «Заказ в Китай» — выберите заказ в поле «Это поставка по заказу».
  3. «Создать поставку» — товар появится в колонке «в пути».
  4. Когда товар пришёл на склад: откройте поставку, проверьте фактическое количество и нажмите «Принять на склад». Недостача останется видна в партии.
  5. Для паспорта и бирок заполните номер партии, дату изготовления и номер паспорта.

{% icon "wallet" %} Цены: завода, учётная, продажи

  • Цена завода (CNY) — из инвойса, справочно.
  • Учётная цена (BYN/шт) — в карточке партии, блок «Учётные цены»: введите курс и общие расходы на партию (доставка, таможня, банк) и нажмите «Рассчитать от курса». Любую цену можно поправить вручную. Видит только руководитель.
  • Цена продажи (BYN без НДС) — подставляется в отгрузку из спецификации заказчика.
  • Прибыль = (цена продажи − учётная цена партии) × кол-во. Знак «≈» — у партии нет своей учётной цены, взята последняя известная.

{% icon "truck" %} Отгрузка, паспорт и бирки

  1. Кнопка «Отгрузка» вверху справа (или «Отгрузить по заявке» в заявке).
  2. Выберите заказчика, дату, изделия и количество. Цену можно не вводить — возьмётся из спецификации. Партию — «авто» (самая старая, где хватает всего количества).
  3. «Провести отгрузку». Если превышен лимит спецификации — появится предупреждение.
  4. В отгрузке: «Паспорт (Word)» и «Бирки (Word)» — раскладка по коробкам и масса брутто из упаковочного листа завода.
  5. Когда ТТН оформлена в 1С — впишите номер и прикрепите скан.

{% icon "file-text" %} Договоры и спецификации

  1. «Договоры» → «+ Договор» (заказчик, номер, дата, скан).
  2. В договоре → «+ Спецификация»: скопируйте таблицу из Excel/Word спецификации и вставьте в поле «Вставить таблицу» → «Разобрать вставку». Проверьте изделия, цены и лимиты → «Сохранить».
  3. Если отгрузки по этой спецификации уже были (например, перенесены из Excel) — нажмите «Привязать» в её карточке.
  4. Новая спецификация на основе старой — «Копировать в новую». Старую закройте кнопкой «Закрыть».

{% icon "clipboard-list" %} Заявки заказчиков

  1. «Заявки» → «+ Заявка»: заказчик, номер/тендер, срок, файл заявки. Строки — вручную или вставкой из Excel.
  2. В заявке видно по каждой позиции: есть на складе, резерв других заявок, в пути, не хватает.
  3. Резерв: пока заявка «в работе», товар закреплён за ней. Очередь — по дате заявки.
  4. «Отгрузить по заявке» — откроется отгрузка с подставленным остатком. Когда всё отгружено — смените статус на «выполнена».
  5. Суммы в BYN без НДС: цена из заявки, иначе из спецификации, иначе из последней продажи. Месячная заявка в деньгах — фильтр по месяцу в списке заявок или «Отчёты → Заявки по месяцам».

{% icon "ship" %} Заказ в Китай

  1. «Заказ в Китай»: сразу отмечено то, чего не хватает под заявки; ниже — что заканчивается по средним продажам. Количество округлено до целой коробки.
  2. «Текст для WeChat» → «Скопировать» → вставьте в чат с заводом. «Чертежи для завода (ZIP)» — приложите архив.
  3. После отправки — «Отправил — сохранить как «в пути»». Когда придёт инвойс, загрузите его в этот заказ (см. «Приход из Китая»).

{% icon "package-minus" %} Списания

«Списания» → выберите причину: брак из Китая, недостача, бесплатные образцы заказчику, инвентаризация (меньше / больше). Остаток пересчитается сам.

{% icon "chart-column" %} Сводка и отчёты

  • Сводка — главная страница: склад, в пути, отгрузки и прибыль за месяц, заявки, что заканчивается.
  • Отчёты → Отгрузки по месяцам — по заказчикам или изделиям, штуки или BYN.
  • Отчёты → Заявки по месяцам — заказано и отгружено в штуках и BYN, выполнение %, сколько не хватает.
  • Отчёты → Заканчивается — чего хватит меньше чем на 4 месяца. Минимальный остаток можно задать в карточке изделия («Изменить»).
  • Прибыль (руководитель) — выручка, себестоимость, маржа.
  • Любой список выгружается в Excel кнопкой «В Excel».

{% icon "info" %} Советы

  • Сервис узнаёт изделия в документах по коду и синонимам. Если в инвойсе или заявке изделие написано по-новому — добавьте синоним в карточке изделия, и в следующий раз оно узнается само.
  • Тёмная тема — кнопка с луной внизу меню.
  • С телефона: нижняя панель — Сводка, Остатки, Отгрузки, Заявки; остальное — «Ещё».
  • Пользователей и роли добавляет администратор в «Настройках». Учётные цены и прибыль видит только группа «Руководитель».
